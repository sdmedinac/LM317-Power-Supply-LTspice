# LM317 Power Supply

## Overview

Adjustable DC power supply designed using the LM317 voltage regulator.

The circuit was first simulated in LTspice and later built on a universal PCB. Experimental measurements were performed using a FNIRSI oscilloscope.

## Features

- 12 VAC transformer input
- Full-wave bridge rectifier (1N4007)
- Dual 4700 µF filter capacitors
- Adjustable LM317 regulator
- Integrated voltmeter and ammeter
- LTspice simulation

## Hardware

### Main Components

- LM317
- 4 × 1N4007
- 2 × 4700 µF electrolytic capacitors
- 220 Ω resistor
- 5 kΩ potentiometer
- Digital voltmeter/ammeter module

## Measurements

- Transformer secondary waveform
- Full-wave rectification
- Filtered DC output
- Regulated output voltage
- Residual ripple analysis
